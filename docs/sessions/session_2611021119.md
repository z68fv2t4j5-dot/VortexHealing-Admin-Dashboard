# Session 2026-11-02 11:19 - Class transcripts searchable from the Handouts page

**Type:** feature. **Branch:** feat/transcripts-kb. **Work item:** none. **Plan:** `docs/plans/PLAN-transcripts-in-kb-2611021110.md`.

## Summary of actions

Daniel has 600+ class and healing-session transcripts as Markdown in a local folder (exported and
sorted in earlier sessions outside this repository). He asked for them to be accessible in the
dashboard. Added `TRANSCRIPTS_DIR` (optional setting), `backend/handouts/transcripts.py` (indexes
the folder as `source_kind='transcript'` on every scan, mirroring teacher notes; folders starting
with `_` and `zoom-import` skipped; family = top folder, date from the file name), a transcripts
count in `store.counts` and `/handouts/status`, a `kinds` filter on `retrieve.search` whose default
(handouts + notes) keeps today's behaviour, a `sources` field on the query endpoints (search mode
only), a `transcripts/` branch on the file endpoint (traversal-guarded), and on the Handouts page a
source selector (visible in Search mode when transcripts exist), a count in the status line and
amber-styled transcript passages with an "Open transcript" link. Answers never use transcripts
(deliberate: unedited speech would swamp the 74 tuned handouts; the eval stays as it is). On
Daniel's machine (outside the repository): `TRANSCRIPTS_DIR` added to `backend/.env`, first full
scan run.
