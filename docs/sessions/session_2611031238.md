# Session 2026-11-03 12:38 - Backend listens on this Mac only

**Type:** bugfix. **Branch:** fix/backend-local-only. **Work item:** none. **Plan:** `docs/plans/PLAN-backend-local-only-2611031221.md`.

## Summary of actions

Daniel asked whether he can view the dashboard from another machine on his network. Checking found the page (Vite) on localhost only, but the backend bound to every interface (`host="0.0.0.0"`), the Mac's application firewall off, and no route behind a login: any device on the network could read students, transcripts and handouts from port 8001 directly. With his go, the backend now binds `127.0.0.1`. Viewing from another machine stays available on demand (`npm run dev -- --host`), documented with the warning that the proxy then exposes every API while it runs. Network viewing was deliberately not made the default; a login is his decision.
